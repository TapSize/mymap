# Політ по колу — GitHub Pages

Ліве та праве коло, МПР / КУР, ручний УС або розрахунок за вітром,
редаговані параметри схеми та сенсорна 3D-анімація. Інтерфейс українською.

## Які файли завантажити

Завантажте **вміст цієї папки в корінь репозиторію**:

```text
index.html
.nojekyll
README.md
```

`index.html` — увесь сайт в одному файлі. Обидві схеми, розрахунки,
іконки та 3D вбудовані. `.nojekyll` вимикає обробку Jekyll.
`README.md` — ця інструкція. Node.js, npm, сервер або складання не потрібні.
Не потрібно завантажувати старі circuit.html, flight-3d.html, flight-model.js,
текстові копії коду, робочу папку проєкту або ZIP-архів замість його вмісту.

## Увімкнути сайт

1. Завантажте три файли у корінь потрібного репозиторію та збережіть commit.
2. Відкрийте **Settings → Pages**.
3. У **Build and deployment → Source** виберіть **Deploy from a branch**.
4. Виберіть гілку з файлами, наприклад **main**, та папку **/(root)**; натисніть **Save**.
5. Після публікації відкрийте адресу, яку покаже GitHub Pages.
   Для репозиторію `flight-circuit` це зазвичай
   `https://YOUR-USERNAME.github.io/flight-circuit/`.

Офіційна інструкція:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

На телефоні/планшеті відкривайте **опубліковану HTTPS-адресу сайту**,
а не перегляд HTML-коду на github.com чи попередній перегляд файлу в «Файлах».

## 3D на телефоні та планшеті

- «3D-політ» відкриває анімацію **всередині поточної сторінки**,
  без нової вкладки, Blob-адреси та спливаючих вікон.
- Один палець — обертання камери.
- Два пальці — плавне наближення/віддалення та переміщення сцени.
- Кнопки **+ / −** — масштаб; **↺** — початковий вигляд.
- «Згори» / «Перспектива» — вид камери; «Прилади» — повна панель.
- «Схема» вгорі — повернення до розрахунків і зупинка анімації.
- Розмір Canvas змінюється при повороті екрана; на мобільних
  обмежені DPR і частота перемальовування для зменшення навантаження.
- Для старіших сенсорних браузерів є резервне керування Touch Events.

## Картки та час

Головні картки розворотів містять окремі МПР, КУР, V (TAS), середню W,
час t та повітряний радіус R. УС і параметри γ/H залишаються доступними.
Картки прямих — S, V, W і t. На прямих t рахується за W; у штиль W = V.
У розворотах W змінюється: час узгоджений з довжиною наземної дуги
та середньою шляховою швидкістю. «ЧАС КОЛА» — результат під схемою ліворуч.

## Налаштування

Автозбереження прив'язане до браузера й адреси сайту. Для перенесення
даних з локального файлу на GitHub Pages спочатку збережіть JSON,
а потім відкрийте його на новому сайті. Можна зберігати ліве, праве
або обидва кола. SVG — рисунок; JSON — редаговані налаштування.

## Межі перевірки

Перевірені числові розрахунки, завантаження параметрів 3D без hash/Blob,
жести, скидання камери, зміна портретної/альбомної орієнтації та DPR
автоматизованими сценаріями. Фізичний iPad/Android-планшет не був доступний
для перевірки. Це навчальна візуалізація, а не сертифікований тренажер.
